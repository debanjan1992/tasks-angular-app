# Task Management App (Angular)

A modern, responsive, and intuitive task management application built using **Angular**, **TypeScript**, and **SCSS**.  
The app helps users organize tasks, plan their day, manage priorities, and stay productive through a simple and smooth UI.

## 📌 Overview

This application allows users to create, organize, and manage tasks across different categories and custom lists.  
It includes features like reminders, daily focus mode ("My Day"), importance markers, and CRUD operations for tasks.

---

## 🛠️ Tech Stack

- **Angular**
- **TypeScript**
- **SCSS**
- **Local Storage** (for saving tasks persistently)
- **Responsive UI**

---

## ✨ Features

### 1. 🔧 Task CRUD (Create, Read, Update, Delete)
- Create new tasks with title, description, and optional meta fields.
- Edit any existing task.
- Delete tasks permanently.
- Mark tasks as **completed** or **active**.

---

### 2. 📅 Task Scheduling
- Set **date** and **time** for any task.
- Tasks with schedules automatically appear under the “Planned” category.
- Helps users keep track of upcoming deadlines.

---

### 3. ⭐ Important Tasks
- Mark any task as **Important**.
- Important tasks appear in their own dedicated list.
- Helps users prioritize what matters most.

---

### 4. ☀️ My Day
- Add tasks to **My Day** to focus on what needs to be done today.
- "My Day" resets every day to encourage fresh planning.
- Great for daily productivity and prioritization.

---

### 5. 📂 Custom Lists
- Users can create totally **custom task lists**.
- Each list can have its own group of tasks.
- Makes it easy to categorize work tasks, personal tasks, shopping lists, or anything else.

---

### 6. 🧑‍💻 Mock Task Generator
- The app can generate **mock/demo tasks** automatically.
- Useful for testing UI, workflows, or showing a demo without manually entering tasks.

---

### 7. 🎨 Clean & Responsive UI
- Built with SCSS and a modern layout.
- Fully responsive and works well on desktop and mobile.
- Animations and transitions for a smooth user experience.

---

## ▶️ Running Locally

```bash
# Install dependencies
npm install

# Run development server
ng serve

# Build for production
ng build --prod
```
